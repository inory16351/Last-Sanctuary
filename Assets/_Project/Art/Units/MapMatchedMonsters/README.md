# Biological Horror Monsters

Ten malignant-tissue monsters designed for the project's `OrganicTilemap`.

- 40 x 40 px transparent PNGs
- PPU 20, matching the map tiles; each sprite occupies 2 x 2 tiles
- Point filter, no mipmaps, alpha transparency
- Diseased muscle, vascular tendrils, nuclei and swollen vesicles in a maroon palette

Use the numbered PNG files in-game. `MapMatchedMonster_Preview.png` is an inspection sheet composited on a representative 20 px floor grid.
