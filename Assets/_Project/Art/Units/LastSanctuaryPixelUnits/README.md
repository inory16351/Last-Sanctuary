# Last Sanctuary Pixel Units

Twelve original enemy sprites for the Last Sanctuary prototype.

- Art style: top-down, high-contrast gothic pixel art.
- Canvas: 96 x 96 px PNG with alpha.
- World footprint: 2 x 2 Unity units at the included 48 Pixels Per Unit import setting.
- Import: Sprite (2D and UI), Point filter, no mipmaps, transparent background.

Files 01-12 are individual sprites. `LastSanctuary_Enemy_Collection.png` is a presentation contact sheet only and is not intended for use as an in-game sprite.
